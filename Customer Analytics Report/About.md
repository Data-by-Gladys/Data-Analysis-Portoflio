## Project Overview

This project presents a Customer Analytics Dashboard developed as part of my Data Analysis training with Axia Africa.

The goal of this project is to analyze customer data and generate actionable insights that can support data-driven decision-making across business functions.

## Objectives

a. Analyze overall customer distribution and behavior

b. Identify trends across age groups, regions, and customer segments

c. Evaluate income patterns and professional profiles

d. Present insights in a clear and interactive dashboard

## Dataset Description

The dataset used for this project contains the following key fields:

Customer ID, Gender, Age & Age Group, Region, Occupation, Income, Customer Segment, Join Date

The data was modeled using a star schema structure, with dimension tables including:

Dim_Gender, Dim_Region, Dim_Segment, Dim_Occupation

## Tools 

Power BI (Data visualization & dashboard creation)

Microsoft Excel (Data cleaning and preprocessing)

## Key Insights
1. Customer Distribution: Total customers are relatively balanced across gender
Majority of customers fall within the Adult and Young Adult categories

2. Regional Performance: The East and South regions show higher customer concentration
The West region has the lowest customer representation

3. Income Analysis: Engineers and Teachers earn the highest average income
Income distribution varies significantly across professions

4. Customer Segmentation: The Retail segment dominates customer count
The Private segment represents the smallest group

5. Trends Over Time: Customer growth fluctuates across years, indicating possible external influencing factors
